# Siren

İki Android uygulaması: **Ana** (QR okuyucu ve siren kumandası) ve **Kullanıcı** (QR gösterir, sesli siren ve görünür bildirimli dinleme hizmeti).

APK üretimi: GitHub Actions > **İki Android APK Derle** > son başarılı çalışma > **Ana-ve-Kullanici-APK**.

Güvenlik: Her iki uygulama internete ve ntfy.sh hizmetine bağlıdır. Uygulama cihaz sahibinin izniyle çalıştırılmalıdır. Acil durum alarmı olarak kullanmayın.
